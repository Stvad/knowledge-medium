# Landscape

Comparisons between Knowledge Medium and adjacent projects. The design docs one level up describe this codebase. These pages describe other people's systems: each is a dated snapshot of what that project's public docs said, plus our reading of what applies here. They carry no status banner. Each page's footer says when its facts were checked, and each section is marked as sourced or as our reading.

- [`cloudflare-os.html`](cloudflare-os.html): Cloudflare OS, an open-source workspace for agent-built apps with a capability-based safety model. Its borrowed ideas are filed as #1427, #1426 and #1425.
- [`imbue-studio.html`](imbue-studio.html): Imbue Studio, a personal computer with a resident agent that can rebuild anything on it. Compared with Cloudflare OS and Knowledge Medium.
